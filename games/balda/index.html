Правила

1. На поле — слово в среднем ряду. Каждый ход добавь одну букву в пустую клетку рядом с занятой.

2. Затем составь слово: касайся клеток по порядку (соседние по стороне, не по диагонали). В слове должна быть новая буква.

3. Очки = длина слова. Клетка ×2 удваивает букву, ×2 С — всё слово. Слова не повторяются.

4. Нет слова — «Пропуск». Два пропуска подряд или полное поле — конец. Больше очков — победа.

Спорное слово: если слова нет в словаре, а оно настоящее, партнёр может его принять.
