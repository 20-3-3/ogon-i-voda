Для 120 Гц на iPhone

Настройки → Приложения → Safari → Дополнения → Feature Flags → выключить «Prefer Page Rendering Updates near 60fps».

Как подключить второй айфон

  1. Оба открывают эту страницу. Аккаунты не нужны.
  2. Первый жмёт «Играть вдвоём по сети» → «Создать комнату» и получает код.
  3. Второй вводит этот код. Без интернета можно подключиться рядом, по Wi-Fi или точке доступа.

Как играть

Огонь безопасно ходит по лаве, вода — по воде. Зелёная жижа опасна обоим. Собирайте кристаллы своего цвета, нажимайте кнопки и рычаги, помогайте друг другу и вместе дойдите до своих дверей.
