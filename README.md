# Java Game

Набор игр для двух (и до шести) телефонов: «Огонь и Вода», «Морской бой», «Призрачный забег», «Артиллерия», «Рисуй-угадай». Играть: https://20-3-3.github.io/ogon-i-voda/games/

Как играть по сети: на стартовой странице (список игр) один раз нажмите «Подключиться». Первый создаёт комнату и получает код из 4 цифр, остальные вводят этот код (или «Рядом, без интернета»: телефоны соединяются напрямую, обмениваясь QR-кодами, через общий Wi-Fi, точку доступа или Bluetooth-модем одного из телефонов — ни интернет, ни Wi-Fi-роутер не нужны). Дальше открывайте любые игры и выбирайте в них игру по сети: связь сохраняется при переходе из игры в игру. Можно играть и на одном телефоне.

Устройство: стартовая страница `games/index.html` держит одну комнату (`games/shared/party.js` + `games/shared/hub.js`), игры открываются внутри неё, а их сетевые модули `duo.js` / `party.js` пользуются этой комнатой.
