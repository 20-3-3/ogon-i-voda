# Огонь и Вода

Кооперативная игра на двоих в духе «Fireboy & Watergirl», 20 уровней. Играть: https://20-3-3.github.io/ogon-i-voda/

Каждый открывает ссылку на своём телефоне. Первый нажимает «Играть вдвоём по сети» → «Создать комнату» и получает код из 4 цифр, второй вводит этот код. Можно играть и вдвоём на одном телефоне.
